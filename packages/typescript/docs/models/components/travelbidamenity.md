# TravelBidAmenity

Amenity details for a travel bid.

## Example Usage

```typescript
import { TravelBidAmenity } from "@cvent/sdk/models/components";

let value: TravelBidAmenity = {
  type: "amenity",
  code: "parking_valet",
  category: "Parking",
  price: 100,
  discountAmount: 90,
  internalCost: 80,
  description: "Valet parking is available for all guests.",
  status: "requested",
};
```
