# HotelRequestRequesterType

Attendee type of the hotel requester. Contact means the requester is an independent attendee. Guest means the attendee is accompanying another attendee.

## Example Usage

```typescript
import { HotelRequestRequesterType } from "@cvent/sdk/models/components";

let value: HotelRequestRequesterType = "Contact";
```

## Values

```typescript
"Contact" | "Guest"
```
