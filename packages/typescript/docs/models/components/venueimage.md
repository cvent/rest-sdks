# VenueImage

A venue image.

## Example Usage

```typescript
import { VenueImage } from "@cvent/sdk/models/components";

let value: VenueImage = {
  name: "Grand Ballroom Exterior",
  description: "Main exterior view of the venue showing the grand entrance.",
  imageGroup: "EXTERIOR",
};
```
