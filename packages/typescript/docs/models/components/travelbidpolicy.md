# TravelBidPolicy

A policy that is associated with a travel bid.

## Example Usage

```typescript
import { TravelBidPolicy } from "@cvent/sdk/models/components";

let value: TravelBidPolicy = {
  code: "cancellation_period",
  category: "cancellation_period",
  value: "24h",
  description: "The cancellation period is 24 hours.",
  status: "requested",
};
```
