# RfpCustomFieldJson

This object contains RFP custom fields attributes only.

## Example Usage

```typescript
import { RfpCustomFieldJson } from "@cvent/sdk/models/components";

let value: RfpCustomFieldJson = {
  customField: {
    id: "50dc08af-24a9-4d01-84be-3d43133dc945",
  },
  answers: [
    "Choice 1",
  ],
};
```
