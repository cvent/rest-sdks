# AccountUserAddress

Represents the address of a Cvent core account user.

## Example Usage

```typescript
import { AccountUserAddress } from "@cvent/sdk/models/components";

let value: AccountUserAddress = {
  address1: "1765 Greensboro Station Pl",
  address2: "7th Floor",
  address3: "",
  city: "McLean",
  countryCode: "US",
  regionCode: "VA",
  postalCode: "22102",
};
```
