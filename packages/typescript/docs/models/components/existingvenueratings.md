# ExistingVenueRatings

The full set of agency ratings and awards for a venue, including all applicable agencies and read-only eligibility flags. Use the GET response as a discovery step before constructing a PUT.

## Example Usage

```typescript
import { ExistingVenueRatings } from "@cvent/sdk/models/components";

let value: ExistingVenueRatings = {
  created: new Date("2017-01-02T02:00:00Z"),
  createdBy: "hporter",
  lastModified: new Date("2019-02-12T03:00:00Z"),
  lastModifiedBy: "hporter",
  ratings: [
    {
      ratingAgency: "AAA",
      ratingValue: "FOUR_DIAMONDS",
      primaryRating: true,
      ratingEditable: true,
      canBePrimary: true,
    },
  ],
  venueAwards: "Recipient of the 2025 Green Hospitality Award.",
  id: "6bb0e2db-861f-46e3-a923-eb4d959ffa00",
  name: "Harbor View Convention Center",
};
```
