# ExhibitLayoutType

The exhibit setup type for a meeting room. Values represent standard exhibit booth and display configurations.

## Example Usage

```typescript
import { ExhibitLayoutType } from "@cvent/sdk/models/components";

let value: ExhibitLayoutType = "BOOTH_10x10";
```

## Values

```typescript

```
