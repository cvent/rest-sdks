# LeadCatcherConfig

Notification and role configuration for a lead catcher contact.

## Example Usage

```typescript
import { LeadCatcherConfig } from "@cvent/sdk/models/components";

let value: LeadCatcherConfig = {
  supplierContactRole: "Sales Manager",
};
```
