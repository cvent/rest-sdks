# VenueAttractionType

Type/category of attraction near a venue.<br><br>Values:<br>- `BLANK` — Indicates no selection, leaves the field blank<br>- `AIRPORT` — Airport<br>- `BUSINESS_DISTRICT` — Business District<br>- `CONVENTION_CENTER` — Convention Center<br>- `HISTORICAL_LANDMARK` — Historical Landmark<br>- `MUSEUM` — Museum<br>- `NIGHTLIFE` — Nightlife<br>- `PARK` — Park<br>- `RECREATION` — Recreation<br>- `SHOPPING` — Shopping<br>- `THEATER` — Theater<br>- `UNIVERSITY` — University

## Example Usage

```typescript
import { VenueAttractionType } from "@cvent/sdk/models/components";

let value: VenueAttractionType = "UNIVERSITY";
```
