# GuestRoomTypeJson

Guest room type. `ANY`: Room can be any type. `SINGLE`: Room with one bed. `DOUBLE`: Room with two beds. `SUITE`: Room is an entire suite. `STAFF`: Room is for staff.

## Example Usage

```typescript
import { GuestRoomTypeJson } from "@cvent/sdk/models/components";

let value: GuestRoomTypeJson = "DOUBLE";
```

## Values

```typescript
"ANY" | "SINGLE" | "DOUBLE" | "SUITE" | "STAFF"
```
