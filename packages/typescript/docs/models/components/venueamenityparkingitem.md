# VenueAmenityParkingItem

A parking amenity selection for a venue. An optional daily rate may be provided for paid parking types.

## Example Usage

```typescript
import { VenueAmenityParkingItem } from "@cvent/sdk/models/components";

let value: VenueAmenityParkingItem = {
  amenity: "STREET_PARKING",
  cost: 25,
};
```
