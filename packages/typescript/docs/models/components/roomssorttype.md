# RoomsSortType

Rooms sort type. CustomOrder: A user-defined sort order. PriceAscending: Data sorted with lowest price first. PriceDescending: Data sorted by highest price first.

## Example Usage

```typescript
import { RoomsSortType } from "@cvent/sdk/models/components";

let value: RoomsSortType = "CustomOrder";
```

## Values

```typescript
"CustomOrder" | "PriceAscending" | "PriceDescending"
```
