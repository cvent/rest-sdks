# GuestRoomOccupancy

Guest room occupancy. `SINGLE`: Single occupant. `DOUBLE`: Two occupants. `TRIPLE`: Three occupants. `QUAD`: Four occupants. 

## Example Usage

```typescript
import { GuestRoomOccupancy } from "@cvent/sdk/models/components";

let value: GuestRoomOccupancy = "SINGLE";
```

## Values

```typescript
"SINGLE" | "DOUBLE" | "TRIPLE" | "QUAD"
```
