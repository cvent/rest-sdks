# ExhibitLayoutType

The exhibit setup type for a meeting room. Values represent standard exhibit booth and display configurations.

## Example Usage

```java
import com.cvent.models.components.ExhibitLayoutType;

ExhibitLayoutType value = ExhibitLayoutType.BOOTH10X10;
```


## Values

| `BOOTH8X10`         | BOOTH_8x10          |
