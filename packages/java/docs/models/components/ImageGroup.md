# ImageGroup

The image group category for a venue image.<br><br>Values:<br>- `AREA_MAP` — Area Map.<br>- `EXTERIOR` — Exterior.<br>- `FLOOR_PLAN` — Floor Plan.<br>- `INTERIOR` — Interior.<br>- `LOBBY` — Lobby.<br>- `LOCAL_ATTRACTIONS` — Local Attractions.<br>- `MEETING_SPACE` — Meeting Space.<br>- `MISCELLANEOUS` — Miscellaneous.<br>- `RECREATION` — Recreation.<br>- `RESTAURANT_LOUNGE` — Restaurant/Lounge.<br>- `SLEEPING_ROOM` — Sleeping Room.<br>- `SMART_PROPOSALS` — Images used in [Smart Custom Proposals](https://support.cvent.com/s/communityarticle/Managing-Images-in-Custom-Proposal-Templates).<br>- `UNCATEGORIZED` — Uncategorized.

## Example Usage

```java
import com.cvent.models.components.ImageGroup;

ImageGroup value = ImageGroup.AREA_MAP;
```
