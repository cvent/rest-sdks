# GuestRoomType

Guest room type. `ANY`: Room can be any type. `SINGLE`: Room with one bed. `DOUBLE`: Room with two beds. `SUITE`: Room is an entire suite. `STAFF`: Room is for staff.

## Example Usage

```java
import com.cvent.models.components.GuestRoomType;

GuestRoomType value = GuestRoomType.ANY;
```


## Values

| Name     | Value    |
| -------- | -------- |
| `ANY`    | ANY      |
| `SINGLE` | SINGLE   |
| `DOUBLE` | DOUBLE   |
| `SUITE`  | SUITE    |
| `STAFF`  | STAFF    |
