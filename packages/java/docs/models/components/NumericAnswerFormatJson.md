# NumericAnswerFormatJson

The answer format that a given number is stored in.

## Example Usage

```java
import com.cvent.models.components.NumericAnswerFormatJson;

NumericAnswerFormatJson value = NumericAnswerFormatJson.CURRENCY;
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `CURRENCY` | Currency   |
| `DECIMAL`  | Decimal    |
| `NUMBER`   | Number     |
