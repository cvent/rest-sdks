# VenueIntegrationType

The type of venue integration a planner prefers when sourcing venues through an RFP. PASSKEY represents Passkey room-block management. CED represents Cvent Event Diagramming (3D diagramming / Interactive Floor Plans).

## Example Usage

```java
import com.cvent.models.components.VenueIntegrationType;

VenueIntegrationType value = VenueIntegrationType.CED;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `CED`     | CED       |
| `PASSKEY` | PASSKEY   |
