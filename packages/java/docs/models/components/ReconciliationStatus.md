# ReconciliationStatus

This is used to denote the reconciliation status for a transaction.

## Example Usage

```java
import com.cvent.models.components.ReconciliationStatus;

ReconciliationStatus value = ReconciliationStatus.RECONCILED;
```


## Values

| Name             | Value            |
| ---------------- | ---------------- |
| `RECONCILED`     | Reconciled       |
| `NOT_RECONCILED` | Not Reconciled   |
