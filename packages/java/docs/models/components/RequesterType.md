# RequesterType

Attendee type of the requester. Contact means the requester is an independent attendee. Guest means the attendee is accompanying another attendee.

## Example Usage

```java
import com.cvent.models.components.RequesterType;

RequesterType value = RequesterType.CONTACT;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `CONTACT` | Contact   |
| `GUEST`   | Guest     |
