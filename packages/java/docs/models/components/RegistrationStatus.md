# RegistrationStatus

This is used to denote the registration status for an event.

## Example Usage

```java
import com.cvent.models.components.RegistrationStatus;

RegistrationStatus value = RegistrationStatus.ACTIVE;
```


## Values

| Name                       | Value                      |
| -------------------------- | -------------------------- |
| `ACTIVE`                   | Active                     |
| `CANCELLED`                | Cancelled                  |
| `CLOSED`                   | Closed                     |
| `COMPLETED`                | Completed                  |
| `DELETED`                  | Deleted                    |
| `NO_REGISTRATION_REQUIRED` | NoRegistrationRequired     |
| `PENDING`                  | Pending                    |
| `PROCESSING`               | Processing                 |
