# OptionalItemType

Denotes the product type of the optional item.

## Example Usage

```java
import com.cvent.models.components.OptionalItemType;

OptionalItemType value = OptionalItemType.DONATION_ITEM;
```


## Values

| Name              | Value             |
| ----------------- | ----------------- |
| `DONATION_ITEM`   | DonationItem      |
| `QUANTITY_ITEM`   | QuantityItem      |
| `MEMBERSHIP_ITEM` | MembershipItem    |
