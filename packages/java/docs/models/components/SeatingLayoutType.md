# SeatingLayoutType

The seating arrangement style for a meeting room. Values represent standard event industry seating configurations.

## Example Usage

```java
import com.cvent.models.components.SeatingLayoutType;

SeatingLayoutType value = SeatingLayoutType.BANQUET;
```
