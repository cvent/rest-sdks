# EventSurveyAvailability

Describes the availability of the event survey

## Example Usage

```java
import com.cvent.models.components.EventSurveyAvailability;

EventSurveyAvailability value = EventSurveyAvailability.EVENT_REGISTRANTS;
```


## Values

| Name                   | Value                  |
| ---------------------- | ---------------------- |
| `EVENT_REGISTRANTS`    | Event Registrants      |
| `EVENT_PARTICIPANTS`   | Event Participants     |
| `SESSION_REGISTRANTS`  | Session Registrants    |
| `SESSION_PARTICIPANTS` | Session Participants   |
