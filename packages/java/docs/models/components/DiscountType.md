# DiscountType

This is used to denote the type of discount

## Example Usage

```java
import com.cvent.models.components.DiscountType;

DiscountType value = DiscountType.AMOUNT;
```


## Values

| Name         | Value        |
| ------------ | ------------ |
| `AMOUNT`     | Amount       |
| `PERCENTAGE` | Percentage   |
