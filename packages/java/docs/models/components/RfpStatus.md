# RfpStatus

Status of the RFP. Returned as ACTIVE when no approval is required, or PENDING when approval is configured.

## Example Usage

```java
import com.cvent.models.components.RfpStatus;

RfpStatus value = RfpStatus.PENDING;
```


## Values

| Name        | Value       |
| ----------- | ----------- |
| `PENDING`   | PENDING     |
| `ACTIVE`    | ACTIVE      |
| `AWARDED`   | AWARDED     |
| `DRAFT`     | DRAFT       |
| `HISTORIC`  | HISTORIC    |
| `CANCELLED` | CANCELLED   |
| `DELETED`   | DELETED     |
