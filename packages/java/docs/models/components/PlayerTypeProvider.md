# PlayerTypeProvider

This is used to denote the type of a video player used for the Cvent Video Player

## Example Usage

```java
import com.cvent.models.components.PlayerTypeProvider;

PlayerTypeProvider value = PlayerTypeProvider.AMAZON_IVS;
```


## Values

| Name         | Value        |
| ------------ | ------------ |
| `AMAZON_IVS` | Amazon IVS   |
| `CVENT_VOD`  | Cvent VOD    |
