# FairSeasonType

The type of the fair season. `blackout`: No special rate is negotiated for the dates, and the Best Available Rates apply.

## Example Usage

```java
import com.cvent.models.components.FairSeasonType;

FairSeasonType value = FairSeasonType.NEGOTIATED;
```


## Values

| Name         | Value        |
| ------------ | ------------ |
| `NEGOTIATED` | negotiated   |
| `BLACKOUT`   | blackout     |
