# NumericAnswerFormat

The answer format that a given number is stored in.

## Example Usage

```java
import com.cvent.models.components.NumericAnswerFormat;

NumericAnswerFormat value = NumericAnswerFormat.CURRENCY;
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `CURRENCY` | Currency   |
| `DECIMAL`  | Decimal    |
| `NUMBER`   | Number     |
