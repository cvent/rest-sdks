# VenueAmenityFacilitySpace

Facility space type available at a venue.

Values:
- `OUTDOOR_SPACE` — Outdoor Space
- `PRIVATE_SPACE` — Private Space
- `SEMI_PRIVATE_SPACE` — Semi-Private Space

## Example Usage

```java
import com.cvent.models.components.VenueAmenityFacilitySpace;

VenueAmenityFacilitySpace value = VenueAmenityFacilitySpace.OUTDOOR_SPACE;
```
