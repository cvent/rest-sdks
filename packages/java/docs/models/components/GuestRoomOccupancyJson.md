# GuestRoomOccupancyJson

Guest room occupancy. `SINGLE`: Single occupant. `DOUBLE`: Two occupants. `TRIPLE`: Three occupants. `QUAD`: Four occupants. 

## Example Usage

```java
import com.cvent.models.components.GuestRoomOccupancyJson;

GuestRoomOccupancyJson value = GuestRoomOccupancyJson.SINGLE;
```

| `SINGLE` | SINGLE   |
