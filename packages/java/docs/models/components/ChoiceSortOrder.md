# ChoiceSortOrder

The sort order for the choices. `AToZ`: sorted alphabetically in ascending order. `AsEntered`: Sorted in the order they were added, oldest choices first. `Random`: Random sort.

## Example Usage

```java
import com.cvent.models.components.ChoiceSortOrder;

ChoiceSortOrder value = ChoiceSortOrder.A_TO_Z;
```


## Values

| Name         | Value        |
| ------------ | ------------ |
| `A_TO_Z`     | AToZ         |
| `AS_ENTERED` | AsEntered    |
| `RANDOM`     | Random       |
