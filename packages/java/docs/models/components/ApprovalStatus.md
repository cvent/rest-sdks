# ApprovalStatus

The approval status of an exhibitor. When absent, the exhibitor is considered approved.

## Example Usage

```java
import com.cvent.models.components.ApprovalStatus;

ApprovalStatus value = ApprovalStatus.PENDING;
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `PENDING`  | PENDING    |
| `APPROVED` | APPROVED   |
| `REJECTED` | REJECTED   |
