# TravelBidWeekendDays

A day of the week that gets the weekend rates of the travel bid.

## Example Usage

```java
import com.cvent.models.components.TravelBidWeekendDays;

TravelBidWeekendDays value = TravelBidWeekendDays.MONDAY;
```


## Values

| Name        | Value       |
| ----------- | ----------- |
| `MONDAY`    | Monday      |
| `TUESDAY`   | Tuesday     |
| `WEDNESDAY` | Wednesday   |
| `THURSDAY`  | Thursday    |
| `FRIDAY`    | Friday      |
| `SATURDAY`  | Saturday    |
| `SUNDAY`    | Sunday      |
