# MeasurementUnit

Values:
- `SQUARE_FEET` — Square Feet
- `SQUARE_METERS` — Square Meters

## Example Usage

```csharp
using Cvent.SDK.Models.Components;

var value = MeasurementUnit.SquareFeet;
```
