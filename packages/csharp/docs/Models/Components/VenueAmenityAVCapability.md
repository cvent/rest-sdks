# VenueAmenityAVCapability

Audio-visual capability available at a venue.

Values:
- `AV_EQUIPMENT` — AV Equipment
- `HIGH_SPEED_INTERNET` — High Speed Internet
- `ONSITE_AV_STAFF` — Onsite AV Staff

## Example Usage

```csharp
using Cvent.SDK.Models.Components;

var value = VenueAmenityAVCapability.AvEquipment;
```
