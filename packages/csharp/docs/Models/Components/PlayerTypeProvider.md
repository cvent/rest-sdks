# PlayerTypeProvider

This is used to denote the type of a video player used for the Cvent Video Player

## Example Usage

```csharp
using Cvent.SDK.Models.Components;

var value = PlayerTypeProvider.AmazonIVS;
```


## Values

| Name        | Value       |
| ----------- | ----------- |
| `AmazonIVS` | Amazon IVS  |
| `CventVOD`  | Cvent VOD   |
