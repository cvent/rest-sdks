# ApprovalStatus

The approval status of an exhibitor. When absent, the exhibitor is considered approved.

## Example Usage

```csharp
using Cvent.SDK.Models.Components;

var value = ApprovalStatus.Pending;
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Pending`  | PENDING    |
| `Approved` | APPROVED   |
| `Rejected` | REJECTED   |
